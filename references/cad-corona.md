# CAD、材质与 Corona 的验收要点

这些是原生工作流中已遇到的问题。按当前输入、Max/Corona 版本和用户要求选用，不能把某次渲染参数变成全局规则。

## STEP 与结构保留

- 导入前确定系统单位；例如毫米模型使用 `units.SystemType = #millimeters`、`units.SystemScale = 1`。
- `ATF_STEP_importer.MeshResolution` 和 `ConvertToMesh` 是有状态的导入参数。先记录，按当前任务设置，在 `finally` 恢复。旧任务使用精度 10 是项目要求，并非每次都设 10。
- 从参考 MAX 借用材质或渲染器前先 `copy`，在全局引用中保留副本，随后才 reset/import；不要覆盖参考文件。
- 记录输入 CAD/参考 MAX 哈希、节点全名和父层级、对象/世界变换、几何顶点与三角形。重开或重新导入后 handle 可能变，不能用旧 handle 绑定零件。
- 若仅允许相机或整组刚体变换，按共同根变换比较零件；不能以材质优化为由移动、重建或删减机械结构。

## 真实元件材质

用户要求查资料时使用厂商资料与其照片核对；把已确认的外观、推测的型号和未知项区分清楚。材质真实感先来自零件识别，再来自参数。

- PCB 不能整块涂成一个颜色：阻焊层、裸露铜/镀金焊盘、锡焊点、黑色芯片、陶瓷电容、USB 金属壳和塑料绝缘应分开。
- 参考电机照片的金属罐体、黑色减速箱、浅色输出轴和红黑导线分别处理。照片仅确认外观时，不凭图猜测精确尺寸或型号。
- PI 电热膜常有琥珀色聚酰亚胺包覆与埋入金属箔。名字含“金属箔”不代表整个对象应成实心铜盘；先看网格剖面、位置和接触面。
- 单个 CAD 网格可能把板材和元件连为一体；按不连通分量分组未必够。可以结合局部坐标、高度、区域、面质心与法线分配 face material ID，而不改顶点和三角形。
- 使用 Multi/Sub、`setFaceMatID` 和 `meshop` UV 接口时，前后校验几何哈希。不同材质仍可共享一个原有网格。
- 共面膜/箔接触面曾引起光学条纹；先处理接触面的 shader 一致性，不擅自移动 CAD 顶点。
- 调壳体白色或透明度时保留屏幕、按钮、黑色结构的独立材质。透明材质和灯光曝光分开调整，并以内部可见性和轮廓清晰度验收。

## 版本与贴图

`CoronaPhysicalMtl`、Max `PhysicalMaterial`、不同 Corona 版本的参数各异。先探测，再设置。需要对同一面中的金属和非金属做区分时，使用明确的材质 ID 或对应的 metallic mask。

RGB/灰度 `Bitmaptexture` 的 `alphaSource` 曾在渲染或重开后从默认 0 规范化为 2。无 Alpha 贴图可在适用版本明确设为 2，以便保存前后比较稳定；有 Alpha 的图像按其真实用途设置。不要为通过检查而忽略所有属性差异。

最终贴图集中在本项目交付目录并保持有效引用。MAX 和贴图一起交付；不能依赖其他任务的临时目录。

## Corona 渲染与 Alpha

1. 明确加载保存的工作 MAX，选择实际存在的相机，设置当前任务的分辨率、采样或噪声目标。先检查材质和构图，再做最终渲染。
2. 属性存在时检查 `alphaAlwaysSolid = false`；PNG 使用 `pngio.setAlpha true` 和适用的颜色类型。输出转换及色彩空间按用户交付用途选，不套用所有工程。
3. VFB 背景透明不等于文件有 Alpha。读取保存的 PNG，检查 RGBA、尺寸、角落 Alpha、部分透明区域和裁切余量。
4. 隐藏背景地面的主射线可见性后，它仍可能通过透明外壳的折射/透射被看见，导致 Alpha 全实。按需要检查次级可见性或 RaySwitch；不要为了透明背景破坏用户需要的反射。
5. 记录渲染开始时 Corona 日志的字节偏移，只解析本次新增行。进度、完成的 pass 数和去噪结束应由新日志或可靠 API 证实。
6. 某些 `CoronaFp` 统计项在渲染结束后返回 0，曾与实际采样/噪声不符。不要把 0 报告成“实测零噪声”；记录目标噪声、可证实的 pass 和未知的实测值。
7. 保存最终 MAX 后重开，比较原有结构、材质分配及关键参数，确认贴图存在。渲染完成标记和文件存在不替代这些验证。

既有任务曾用 1600×2000、64 pass 等设置；它们只属于当时的交付要求。新任务由用户要求、质量检查与资源情况决定。
